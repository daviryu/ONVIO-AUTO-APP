**1º passo - abrir o aplicativo ONVIO\_AutoUploader.exe.**



**2º passo - clickar no botão "FAZER CONEXÃO (Abrir o Chrome)"**
	**Muito importante** manter a aba que foi aberta e conectar a conta da ONVIO, é por esta aba que o aplicativo fará o caminho de upload.



**3º passo - inserir o código de identificação do cliente.**
Código usado para identificar o cliente especifico no site da ONVIO.



**4º passo - selecionar os arquivos .pdf dos boletos.**
O usuario pode procurar manualmente o caminho dos arquivos pelo botão "procurar" ou pode arrastar e soltar os arquivos na area indicada.



**5º passo - clickar no botão "CONFIRMAR DADOS E FAZER UPLOAD".**
Muito importante que o usuario confirme se todos os dados estão corretos, pois caso não estejam o processo irá falhar.





Obs: o usuario pode deixar a aba do Chrome que foi aberta, no monitor secundario e continuar o seu trabalho no monitor principal.



Obs: é necessario desativar o controle inteligente de aplicativos do windows.
